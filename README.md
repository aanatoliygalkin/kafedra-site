# Сайт кафедры информационных систем в экономике и управлении

**Руководство для сотрудников кафедры.**
Как открыть сайт, найти нужный раздел и самостоятельно разместить новость,
документ или изменить сведения о преподавателе — без программиста и без вёрстки.

**Адрес сайта:** <https://aanatoliygalkin.github.io/kafedra-site/>

---

## 1. Что это за сайт

Сайт кафедры АНО ВО «РосНОУ» публикует сведения о кафедре в открытом доступе:
новости, состав кафедры, дисциплины учебного плана, учебные планы и бланки
документов, страницы «О кафедре», «Поступающим», «Контакты».

Все материалы размещаются через **панель управления**: сотрудник заполняет поля
в форме, и запись сразу появляется на странице сайта. Готовить HTML-страницы,
верстать и обращаться к разработчику для каждой новости не нужно.

## 4. Вход в панель управления

1. Откройте сайт и нажмите **«Вход»** в правом верхнем углу (или перейдите
   по адресу `/login/`).
2. Введите служебную почту и пароль, выданные администратором сайта.
3. После входа в шапке появляются кнопки **«Панель»** и **«Выйти»**.

Для демонстрационной версии сайта предусмотрены две учётные записи:

| Учётная запись | Пароль | Роль |
| --- | --- | --- |
| `admin@iseu.local` | `admin123` | администратор — все разделы и управление учётными записями |
| `staff@iseu.local` | `staff123` | сотрудник кафедры — содержание разделов |

Что видно посетителю, а что сотруднику:

| Роль | Права |
| --- | --- |
| гость (без входа) | просмотр опубликованных новостей, справочников и документов |
| сотрудник кафедры | редактирование содержания: новости, преподаватели, дисциплины, документы, страницы |
| администратор | всё перечисленное плюс управление учётными записями и правами |

Служебный раздел закрыт от посетителей: при попытке открыть `/admin/` без входа
сайт переадресует на форму входа.

## 5. Панель управления: обзор

После входа открывается страница **«Обзор»**: число записей в каждом разделе,
последние новости и кнопка **«+ Новая новость»**.

Слева — разделы панели:

* **Новости** — публикации и объявления;
* **Преподаватели** — состав кафедры;
* **Дисциплины** — учебный план;
* **Документы** — архив PDF-файлов;
* **Страницы** — текстовые страницы («О кафедре», «Поступающим», «Контакты», «Карта сайта»).

В каждом разделе есть таблица записей, поле **«Поиск»**, кнопка **«+ Добавить»**
и в каждой строке — кнопки **«Изменить»** и **«Удалить»**. Изменения сразу
отображаются на страницах сайта.

## 6. Как добавить новость

1. Панель → **«Новости»** → **«+ Добавить»**.
2. Заполните поля (обязательные отмечены звёздочкой в форме):

| Поле | Что вписать |
| --- | --- |
| Заголовок \* | короткое название публикации, до 80–90 знаков |
| Адрес записи | можно оставить пустым — будет создан из заголовка автоматически |
| Раздел | один из пяти: Учёба, Студенты, Расписание, Наука, Приём |
| Дата публикации | дата, которую увидят посетители |
| Опубликовать на сайте | галочка: снята — запись остаётся черновиком и посетителям не видна |
| Ссылка на обложку | необязательно: адрес картинки, если нужна иллюстрация |
| Краткое описание | 1–2 предложения для карточки в ленте |
| Текст новости \* | основной текст |

3. Нажмите **«Сохранить»** — откроется список новостей, запись появится
   в таблице со статусом «Опубликована» или «Черновик».
4. Проверьте результат на сайте: «Новости» → ваша публикация.

Особенности:

* **Абзацы разделяются пустой строкой** — так они и будут показаны на странице.
* Если запись сохранена как **черновик**, она видна только в панели; чтобы
  показать её посетителям, откройте запись, поставьте галочку «Опубликовать
  на сайте» и сохраните снова.
* В карточке ленты выводится «Краткое описание»; если оставить поле пустым,
  будет показано начало текста.
* Новость можно править и после публикации — дата при этом не меняется,
  если вы её не изменили сами.

## 7. Как добавить или изменить преподавателя

Панель → **«Преподаватели»** → **«+ Добавить»**. Поля:

| Поле | Что вписать |
| --- | --- |
| Фамилия, имя, отчество \* | полностью, например «Иванова Мария Сергеевна» |
| Должность \* | как в трудовом договоре: «доцент», «старший преподаватель» |
| Учёная степень, звание | например «кандидат технических наук, доцент» |
| Электронная почта | служебный адрес; на сайте он станет ссылкой |
| Телефон | с добавочным номером, если есть |
| Дисциплины | через запятую; список выводится в карточке |
| Стаж, лет | число |
| Порядок вывода | число: 1 — первый в списке, 99 — последний |
| Заведующий кафедрой | галочка: карточка выделяется как карточка заведующего |
| Ссылка на фотографию | необязательно: адрес фотографии |

Карточки на странице «Преподаватели» выводятся по полю «Порядок вывода»,
поэтому заведующего удобно закрепить первым.

## 8. Как добавить или изменить дисциплину

Панель → **«Дисциплины»** → **«+ Добавить»**. Поля: код дисциплины, название,
семестр, всего часов, зачётные единицы, форма обучения (очная, очно-заочная),
преподаватель (выбирается из уже внесённого списка) и описание.

Название преподавателя на сайте подставляется из справочника: если исправить
фамилию в разделе «Преподаватели», она изменится и в таблице дисциплин.
Отдельно вводить её не нужно.

---

## 9. Как добавить документ в архив

Панель → **«Документы»** → **«+ Добавить»**. Поля: название документа,
категория (Учебные планы, Методические материалы, Бланки, Приказы), версия
(например `2026`), ссылка на файл, размер в байтах и дата обновления.

Порядок для нового файла:

1. Файл сохраняется в формате **PDF** и с именем латиницей без пробелов,
   например `rp-bazy-dannyh-2026.pdf`.
2. Файл передаётся администратору сайта — он кладёт его в папку `public/files`
   репозитория. Именно поэтому в поле «Ссылка на файл» указывается путь вида
   `/files/rp-bazy-dannyh-2026.pdf`.
3. В панели создаётся запись с этим путём, названием, категорией и версией.
4. Проверьте скачивание: «Документы» → выберите категорию → нажмите на строку.

Размер в байтах можно не заполнять точно — он влияет только на подпись рядом
со ссылкой; при необходимости администратор уточнит его одной командой.

## 10. Как изменить текст страницы «О кафедре», «Поступающим», «Контакты»

Панель → **«Страницы»**. В списке четыре записи: «О кафедре»
(`about`), «Поступающим» (`admission`), «Контакты» (`contacts`), «Карта сайта»
(`sitemap`). Откройте нужную, измените заголовок и текст, сохраните.

Поле **«Адрес страницы»** менять не нужно: на него ссылаются меню сайта,
подвал и кнопки на главной странице. Если изменить адрес, посетители получат
ошибку «Страница не найдена».

Абзацы, как и в новостях, разделяются пустой строкой.

## 11. Как изменить или удалить запись

* **Изменить:** раздел панели → найдите запись поиском → кнопка «Изменить» →
  правка → «Сохранить».
* **Удалить:** кнопка «Удалить» в строке таблицы или «Удалить запись» в форме.
  Сайт переспросит подтверждение — удаление отменить нельзя.
* Если запись нужно просто временно убрать с сайта, удалять её не обязательно:
  снимите галочку **«Опубликовать на сайте»** (для новостей) — запись останется
  в панели как черновик.

## 12. Правила оформления

* Заголовок новости — с заглавной буквы, без точки в конце, без «!!!».
* Даты — только через поле выбора даты, не текстом.
* Категория выбирается из списка; новые категории не добавляются
  (это потребует правки сайта).
* Текст — обычными абзацами, без ручных переносов строк и без разметки.
* Документы — PDF; сканы должны быть читаемыми, вес одного файла желательно
  до 5 МБ.
* Персональные данные (телефоны, почта) публикуются с согласия сотрудника.

## 13. Чек-лист перед публикацией

1. Публикация открыта на сайте и выглядит правильно.
2. Дата и раздел (категория) указаны верно.
3. Нет опечаток в фамилиях, названиях дисциплин и номерах приказов.
4. Ссылки и файлы открываются.
5. Старая, потерявшая актуальность запись снята с публикации или обновлена.

## 14. Важно: демонстрационный режим

Опубликованная по адресу выше копия сайта работает в **демонстрационном
режиме**: база данных к ней не подключена, записи сохраняются в браузере того
компьютера, где их вносят.

Что это значит на практике:

* вы можете свободно показывать панель, добавлять и удалять записи — пока сайт
  открыт **в этом же браузере**, записи видны на страницах;
* на другом компьютере, после очистки истории браузера или в режиме
  инкогнито сайт покажет исходный набор материалов;
* исходный набор материалов для демонстрации хранится в файле
  `src/lib/demo-data.ts`.

Чтобы правки стали общими для всех посетителей, к сайту нужно подключить базу
данных (Supabase, PostgreSQL). Это работа администратора сайта: в репозитории
уже лежат готовые SQL-скрипты схемы, правил доступа и демонстрационных данных
(каталог `supabase/`), а параметры подключения задаются переменными окружения.
Порядок подключения, состав таблиц и правила доступа описаны в пояснительной
записке к выпускной квалификационной работе.

## 15. Если что-то не работает

| Что произошло | Что делать |
| --- | --- |
| Не пускает по паролю | проверьте раскладку и регистр; пароль выдаёт администратор сайта — восстановления «самостоятельно» нет |
| Добавил новость, а её нет на сайте | в записи не стоит галочка «Опубликовать на сайте» — включите её и сохраните |
| Правки видны мне, но не видны коллеге | это демонстрационный режим (раздел 14): записи хранятся в браузере |
| Обновил страницу — правки пропали | браузер работает в режиме инкогнито или очищена история; внесите запись заново в обычном окне |
| Документ не скачивается | файла нет по указанному пути — передайте PDF администратору сайта и проверьте поле «Ссылка на файл» |
| Не открывается раздел, ошибка 404 | адрес набран с ошибкой; вернитесь на главную и перейдите по меню |
| Страница «Контакты» открылась пустой | запись с адресом `contacts` удалена или её адрес изменён — восстановите адрес `contacts` в панели |
