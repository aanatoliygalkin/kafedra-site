# Сайт кафедры информационных систем в экономике и управлении

Учебный проект — бакалаврская работа по направлению 09.03.03 «Прикладная
информатика»: веб-сайт кафедры АНО ВО «РосНОУ» с панелью управления,
справочниками и архивом документов.

- Сайт: <https://aanatoliygalkin.github.io/kafedra-site/>
- Стек: Next.js 14, React 18, TypeScript, Supabase (PostgreSQL 15), GitHub Pages.
- Публикация: автоматически из ветки `main` через GitHub Actions, сборка в `out/`.
- Опубликованная копия работает в демонстрационном режиме: данные хранятся в
  браузере, вход в панель — `admin@iseu.local` / `admin123`.
- Подключение базы: выполнить `supabase/001_init.sql` … `004_seed.sql` и задать
  `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` (см. `.env.example`).
- Локальный запуск: `npm install`, `npm run dev`; сборка — `npm run build`.
- Руководство для сотрудников кафедры — [GUIDE.md](GUIDE.md).

Проект выполнен в учебных целях и не предназначен для промышленной эксплуатации.
